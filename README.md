# Finding stories in data using AI

This repo contains resources for a webinar on using AI to find stories in data. 

## Data to work with

You can get some data to try out some data analysis techniques on the [Gender pay gap service's download page](http://gender-pay-gap.service.gov.uk/viewing/download). Make sure to download the latest FULL year rather than the current year (most data isn't submitted until the end of the financial year).

You will need to attach the data to a prompt in ChatGPT/Gemini/Claude or another AI tool. 

*Note: on free accounts you will hit daily limits quickly with attachments and data analysis, so you may want to decide which prompts are the highest priority first.*

## Using Google Colab

[Google Colab](http://Colab.google.com) is part of Google Drive, and allows you to run Python without having to install it on your machine. 

This is very useful for storing and reading the code your AI tool has used to perform any analysis, to check it, and to run it yourself. 

Go to http://Colab.google.com and create a new notebook. It will open with an empty code block where you can paste any code copied from the AI tool, and press the 'play' button to run it. 

You will need to ask the AI tool to make sure that its code can be used in Colab, rather than the code that it's running in the AI's built-in sandbox or that might be run on your own computer.
