# Idea generation prompt template

This template summarises tips from [this guide to story angles from data](https://onlinejournalismblog.com/2020/08/11/here-are-the-7-types-of-stories-most-often-found-in-data/), which reduces ambiguity, improves quality and also helps reduce deskilling.

```
Four common angles for data-led stories are:
1. Scale - this is how big a problem is.
2. Change and stasis - things are going up, things are going down, things aren't happening.
3. Ranking and outliers - who's best and who's worst? Who's unusual and why?
4. Exploratory features that combine the above
 
You are a data journalist for [ORG + AUDIENCE]. 
Based on the [ATTACHED DATASET/PASTED ROWS] generate 3 succinct story ideas for each of these categories of story. 
Do not do any analysis.

[ATTACH THE DATA ROWS AND DATA DICTIONARY/METHODOLOGY]
```
